O que é a máscara

Um endereço IPv4 tem 32 bits, divididos em 4 octetos de 8 bits. A máscara diz quais bits são rede (1) e quais são host (0). Os 1s ficam sempre juntos à esquerda, então basta contar quantos são: esse número é o prefixo CIDR.

/26 = 26 bits em 1 = 11111111.11111111.11111111.11000000 = 255.255.255.192

Do /24 ao /32 os três primeiros octetos são sempre 255.255.255. Só o último muda, e ele é a soma dos pesos dos bits acesos:

bit 1128/25 → 128
bit 264/26 → 192
bit 332/27 → 224
bit 416/28 → 240
bit 58/29 → 248
bit 64/30 → 252
bit 72/31 → 254
bit 81/32 → 255

A linha laranja é a soma acumulada: 128, 128+64=192, 192+32=224 e assim por diante. Decore essa sequência e você tem todas as máscaras.

As três contas que resolvem tudo

  • Bits de host = 32 − prefixo. Ex.: /27 → 5 bits.
  • Endereços no bloco = 2bits de host. Ex.: 2⁵ = 32. Também é 256 − último octeto da máscara (256 − 224 = 32).
  • Hosts utilizáveis = bloco − 2 (tira o endereço de rede e o de broadcast). Ex.: 32 − 2 = 30.

As sub-redes começam em múltiplos do bloco. Num /27 (bloco 32): .0, .32, .64, .96, .128, .160, .192, .224.

⚠ Pegadinha de prova

/31 e /32 fogem da regra “bloco − 2”. O /31 (RFC 3021) usa os 2 endereços em links ponto a ponto, sem rede nem broadcast. O /32 identifica um único host: loopback de roteador, rota de host, regra de firewall para um IP só.

⚠ Não confunda

Wildcard é a máscara invertida (255 − cada octeto). Aparece em ACL Cisco e no network do OSPF: /26 vira 0.0.0.63. A máscara diz o que é rede; a wildcard diz quais bits podem variar.
